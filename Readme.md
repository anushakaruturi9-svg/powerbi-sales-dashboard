# 📊 Power BI Sales Dashboard

## 📌 Project Overview

This project is an interactive Sales Dashboard developed using **Microsoft Power BI** and the **Sample Superstore** dataset. It provides valuable business insights into sales performance, profitability, customer behavior, and regional trends through interactive visualizations and DAX calculations.

---

## 🎯 Project Objectives

- Analyze Sales and Profit performance
- Track business KPIs
- Identify top-performing categories and regions
- Discover key business insights using AI visuals
- Build an interactive dashboard for business users

---

## 🛠 Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- GitHub

---

## 📂 Dataset

- Sample Superstore Dataset (CSV)

---
